2Architecture Test

One structural rule that actually runs, with the command (R1.7)

Problem statement

Encode exactly one structural rule as a test that actually runs, with the command written down. One test that runs beats five that are described. It must pass or fail deterministically for the same codebase state.

What we did

  • Added DomainDependencyRuleTests to the xUnit project, encoding one rule: InvoiceApp.Domain must not depend on web or storage assemblies — enforcing the AGENTS.md convention "business rules, no web or storage code."
  • Implemented by reflection over the Domain assembly's referenced assemblies vs. a forbidden-prefix list (Microsoft.AspNetCore, Microsoft.EntityFrameworkCore, Microsoft.Data.SqlClient, System.Data.SqlClient, Azure.). Reads only the codebase — no network.
  • Ran it green three times for determinism — Passed: 1, Failed: 0, exit 0 each run.
dotnet test backend/InvoiceApp.sln --filter FullyQualifiedName~DomainDependencyRuleTests
# also runs under: dotnet test backend/InvoiceApp.sln
